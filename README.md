## 🎯 What is SolaMate?

**SolaMate** is a next-generation Web3 social finance platform built on Solana that seamlessly combines:

- 🤖 **AI-Powered Interactions** - Natural language commands for blockchain transactions
- 💬 **Social Features** - On-chain messaging, friend system, and social graph
- 💰 **Financial Tools** - Expense tracking, bill splitting, and funding events
- 🐾 **Gamification** - Virtual pet companions with XP, levels, and rewards

Whether you're splitting dinner with friends, tracking your crypto spending, or just chatting with your virtual pet, SolaMate makes Web3 feel natural and fun.

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18+ ([Download](https://nodejs.org))
- **Solana CLI** ([Install Guide](https://docs.solana.com/cli/install-solana-cli-tools))
- **Phantom** or **Solflare** wallet browser extension

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/solamate.git
cd solamate

# 2. Install dependencies
cd frontend
npm install

# 3. Configure environment
cp .env.example .env.local
```

### Environment Variables

Edit `.env.local` with your keys:

```env
# Solana
NEXT_PUBLIC_SOLANA_RPC_URL=https://api.devnet.solana.com
NEXT_PUBLIC_SOLANA_NETWORK=devnet

# IPFS (Pinata)
PINATA_JWT=your_pinata_jwt_token

# AI - Gemini (OCR only)
GEMINI_API_KEY=your_gemini_api_key

# AI - DeepSeek (AI chat & pet chat)
DEEPSEEK_API_KEY=your_deepseek_api_key
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```
